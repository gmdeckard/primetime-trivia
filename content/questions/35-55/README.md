# Questions for 35-55

Written for 35 to 55: formative years roughly 1981 to 2016.

Deliberately era-locked rather than general knowledge. The first version of
this set turned out to be mostly timeless questions, so those were moved into
the core bank where they earn their keep every night, and this replaces them
with material the main 55-75 bank will not touch. That keeps a beta night
genuinely separate from the questions a resident will be asked in January.

Eight categories, ten each, shaped 2/5/3 across difficulties 2, 3 and 4, so
any one of them fills a ten-question round alone. A night is six rounds.
