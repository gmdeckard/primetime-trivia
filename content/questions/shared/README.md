# Questions for every age group

A folder under `questions/` normally names the age group it is written for,
and the loader tags every question in it accordingly. `shared/` is the one
that does not: nothing in here is tagged, and an untagged question is in play
whichever age group the MC picks.

That is not a loophole, it is the point. The numeric tiebreakers live here
because a tie at the top has to be breakable on a kids night as much as on a
55-75 night, and there is nothing age-specific about guessing the height of a
waterfall. Before this folder existed they achieved the same thing by being
the one file in the bank with no `audience:` key, which worked and explained
itself to nobody.

Put something here only when it genuinely suits an eight-year-old and a
seventy-five-year-old equally. Everything else belongs in an age folder, even
if that means writing it twice.
